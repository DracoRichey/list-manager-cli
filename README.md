# list-manager-cli

A Python CLI application that allows users to view, add, and delete names, persisting data in a local text file.

## Features
- View items in numbered list
- Add new items
- Delete items by number
- Input validation for user errors
- Persistent data storage between runs

## How to Run
- Requires Python 3 (tested on 3.13.7)
- Run using: `python List_managerV1.py`

## What I Learned
- Defensive programming through input validation and bounds checking
- File I/O for persistent data storage using text files
- List indexing concepts, including converting user input to safe indexes
- Building a CLI application using loops and functions
